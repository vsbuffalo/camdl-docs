Rough working notes + figures for the v3 rewrite of the WA seed-timing chapter. Built up section-by-section as we go. Eventually distilled into a clean .qmd. Predecessor: v2 verify dir (preserved in guide/fitting/seed-timing-v2/).

Premise of v3 rewrite: the v1 and v2 chapter used a plain SIR model with COVID-specific γ pinned. Two mistakes acknowledged: (a) SIR with exponential generation interval is wrong for a respiratory virus with real latent period — biases R₀ and τ; (b) using COVID-specific parameter values conflates the "with hindsight" framing with the "real-time analyst" framing. v3 uses SEIR with pre-COVID coronavirus priors (Feb-2020 vintage) per priors doc.

Plan / structure

  3. Apply to real WA — naive fit (loose priors)
  4. 2D profile L(t_seed, n_seed) on real WA
  5. Sensitivity to (ρ_max, t_rep) at the profile MLE
  6. Bedford monophyly anchor: pin n_seed=1 and recompute τ
  7. Discuss identifiability, ridges, and what the chapter's headline answer is
